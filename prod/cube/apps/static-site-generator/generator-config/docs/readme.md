## 1. 系统概述

本系统是一套**可视化静态站点搭建与发布平台**。你可以通过拖拽组件的方式搭建网站页面，管理文章内容，上传素材图片，最后一键构建并部署到七牛云 CDN。

### 1.1 核心概念

| 概念 | 说明 | 类比 |
|------|------|------|
| **布局（Layout）** | 网站的"外壳"，包含导航栏、页脚、侧边栏等全局元素 | 像 WordPress 的主题框架 |
| **页面（Page）** | 网站的"内容页"，填充到布局的内容插槽中 | 像 WordPress 的单个页面 |
| **组件** | 页面中的各种功能区块，如轮播图、产品展示、文章列表等 | 像 Elementor 的 widget |
| **文章** | 资讯/新闻类的内容，有分类体系，支持富文本编辑 | 像 CMS 的文章系统 |
| **素材** | 图片、视频等文件资源 | 像媒体库 |
| **制品** | 一次构建产出的静态站点压缩包 | 像编译后的 dist 文件夹 |

### 1.2 后台菜单总览

```
├─ 站点设置          → 配置网站名称、域名、Logo、SEO、统计代码
├─ 素材管理          → 上传和管理图片、视频等文件
├─ 页面管理
│   ├─ 页面列表      → 管理所有页面（首页、关于我们、产品页等）
│   ├─ 布局列表      → 管理页面布局（导航栏+页脚的框架）
│   ├─ 页面内容编辑  → 拖拽组件搭建页面内容
│   └─ 布局内容编辑  → 拖拽组件搭建布局框架
├─ 文章管理
│   ├─ 文章列表      → 管理资讯/新闻文章
│   ├─ 文章分类      → 管理文章分类体系
│   └─ 文章内容编辑  → 富文本编辑器写文章
├─ 咨询列表          → 查看网站访客提交的咨询表单
├─ 部署配置          → 配置七牛云对象存储参数
└─ 构建部署          → 触发构建、查看状态、发布上线
```

### 1.3 标准工作流程

```
Step 1: 站点设置    → 填写网站名称、域名、上传 Logo
    ↓
Step 2: 素材管理    → 上传网站所需的图片素材
    ↓
Step 3: 页面管理    → 创建布局 → 创建页面 → 绑定布局 → 拖拽组件搭建内容
    ↓
Step 4: 文章管理    → 创建分类 → 撰写文章（可选）
    ↓
Step 5: 部署配置    → 填写七牛云 AccessKey、SecretKey、Bucket 等
    ↓
Step 6: 构建部署    → 点击「新建制品」→ 等待构建成功 → 点击「发布」
    ↓
Step 7: 验证        → 访问网站域名，确认内容正常显示
```

## 2. 前置准备（七牛云控制台）

在后台操作之前，请先在七牛云控制台完成以下准备工作。

### 2.1 创建对象存储空间（Bucket）

1. 登录 [七牛云控制台](https://portal.qiniu.com/)
2. 进入「对象存储 Kodo」→「空间管理」→「新建空间」
3. 输入空间名称（如 `kaihe-site`），选择存储区域
4. **访问控制选择「公开」**（静态站点必须公开才能被访问）
5. 记录以下信息备用：
   - **Bucket 名称**
   - **存储区域**（如华东 `z0`、华北 `z1`、华南 `z2`）

### 2.2 绑定自定义域名

1. 进入刚创建的空间 →「域名管理」→「自定义 CDN 加速域名」
2. 添加你的域名，如 `kaihe.guhecloud.com`
3. 按页面提示，到你的域名 DNS 服务商处添加 **CNAME 记录**
4. 返回七牛控制台，等待域名状态变为「**正常**」
5. 记录这个**自定义域名**，后续配置中会用到

> ⚠️ **注意**：CNAME 解析生效可能需要几分钟到几小时不等，请耐心等待状态变为「正常」后再进行后续操作。

### 2.3 获取 API 密钥

1. 七牛控制台右上角 →「密钥管理」
2. 创建或复制已有密钥对的：
   - **AccessKey**
   - **SecretKey**（仅在创建时显示一次，请复制保存到安全的地方）

> ⚠️ **安全提醒**：SecretKey 相当于密码，请勿泄露给他人或提交到代码仓库。

## 3. 站点设置

**入口**：后台左侧菜单 →「站点设置」

**功能**：配置网站的全局基础信息，这些信息会写入站点的配置文件中，最终被打包进构建产物并显示在网页上。

### 3.1 页面基本配置

| 配置项 | 必填 | 说明 |
|--------|------|------|
| 网站名称 | ✅ | 站点标题，显示在浏览器标签页和导航栏 Logo 旁边 |
| **网站地址** | ✅ | **完整的 HTTPS 地址**，如 `https://kaihe.guhecloud.com`。这是七牛 CDN 绑定的域名，部署时会自动作为 CDN 刷新目标 |
| 分享图 | ✅ | OG 图片（Open Graph），用于微信/社交媒体分享时展示的封面图 |
| Favicon | ✅ | 浏览器标签页左上角的小图标 |
| 主色 | ❌ | 网站主题色，影响按钮、链接等颜色，默认 `#1578FF` |
| 导航样式 | ❌ | `light`（浅色背景深色文字）或 `dark`（深色背景浅色文字） |

> 💡 **提示**：分享图和 Favicon 需要先在「素材管理」中上传图片，然后在此页面点击「选择素材」从素材库中选取。

### 3.2 全局默认 TDK（SEO 配置）

| 配置项 | 说明 |
|--------|------|
| 默认标题 | 当页面没有单独设置标题时使用的默认 `<title>` |
| 默认描述 | 当页面没有单独设置描述时使用的默认 `<meta name="description">` |
| 默认关键词 | 当页面没有单独设置关键词时使用的默认 `<meta name="keywords">` |

> 💡 **提示**：每个页面可以在「页面内容编辑」中单独配置 SEO 信息，单独配置会覆盖这里的全局默认值。

### 3.3 统计代码配置

如果你有百度统计、Google Analytics、友盟统计等需求：

1. 点击「添加脚本」按钮
2. 在文本框中粘贴完整的统计代码（通常是 `<script>` 标签）
3. 可以添加多个统计脚本
4. 保存时系统会自动过滤空白的脚本

> 💡 **提示**：统计代码保存后会注入到所有页面的 `<head>` 中。修改统计代码后需要重新构建并发布才能生效。

### 3.4 保存与生效

填写完所有信息后，点击页面右下角「**保存**」按钮。保存成功后：
- 站点设置信息会存入数据库
- **但这不会立即更新线上网站**
- 需要到「构建部署」页面重新构建并发布，新的设置才会生效

## 4. 页面管理

**入口**：后台左侧菜单 →「页面管理」

页面管理是整个系统最核心的模块，包含四个子功能：**页面列表**、**布局列表**、**页面内容编辑**、**布局内容编辑**。

### 4.1 核心概念：布局 vs 页面

在操作之前，必须先理解**布局**和**页面**的区别：

**布局（Layout）—— 网站的"外壳"**
- 包含所有页面共享的元素：顶部导航栏（NavMenu）、底部页脚（SiteFooter）
- 布局中有一个「内容插槽」，页面的内容会填充到这个插槽中
- 一个布局可以被多个页面共用
- 修改布局会影响所有绑定该布局的页面

**页面（Page）—— 网站的"内容"**
- 包含页面的具体内容：轮播图、产品展示、案例列表等
- 页面必须绑定一个布局
- 页面的内容会渲染到布局的内容插槽中
- 每个页面有独立的路由地址（如 `/`、`/about.html`）

**举例说明**：
```
布局 = 一套「信封」：信封上印有统一的抬头和落款
页面 = 「信纸」上的内容：每封信的内容不同

首页（页面）→ 绑定「默认布局」→ 显示：导航栏 + 首页内容 + 页脚
关于我们（页面）→ 绑定「默认布局」→ 显示：导航栏 + 关于我们内容 + 页脚
产品中心（页面）→ 绑定「默认布局」→ 显示：导航栏 + 产品内容 + 页脚
```

### 4.2 布局列表

**入口**：后台左侧菜单 →「页面管理」→「布局列表」

**功能**：管理网站的所有布局模板。

#### 4.2.1 创建新布局

1. 点击「**新增**」按钮
2. 进入布局编辑页面
3. 切换到「布局信息」标签，填写**布局名称**（如「默认布局」）
4. 切换到「布局内容」标签，进入可视化设计器
5. 从左侧组件面板拖拽组件到画布：
   - **NavMenu**：顶部导航栏（必须）
   - **内容插槽**：页面内容的占位符（必须，且只能有一个）
   - **SiteFooter**：底部页脚（可选）
   - **FloatingSidebar**：悬浮侧边栏（可选）
6. 点击画布上的组件，在右侧配置面板中设置组件属性
7. 点击右下角「**保存**」

#### 4.2.2 编辑布局

1. 在布局列表中找到要修改的布局
2. 点击「**编辑**」
3. 在可视化设计器中调整组件顺序、修改组件配置
4. 点击「**保存**」

> ⚠️ **重要**：修改布局后，所有绑定该布局的页面都会受影响。如果只想改某个页面的内容，应该去编辑**页面**，而不是布局。

#### 4.2.3 删除布局

1. 在布局列表中找到要删除的布局
2. 点击「**删除**」
3. 确认删除

> ⚠️ **注意**：如果有页面正在使用这个布局，删除后这些页面可能无法正常显示。请先确保没有页面绑定该布局，或先将页面绑定到其他布局。

### 4.3 页面列表

**入口**：后台左侧菜单 →「页面管理」→「页面列表」

**功能**：管理网站的所有独立页面。

#### 4.3.1 页面列表字段说明

| 字段 | 说明 |
|------|------|
| 页面名称 | 页面的名称，仅在后台显示 |
| 页面路由 | 页面的访问地址，如 `/`、`/about.html`、`/product.html` |
| 页面标题 | 页面的 SEO 标题（`<title>` 标签内容） |
| 创建时间 | 页面首次创建的时间 |
| 更新时间 | 页面最后修改的时间 |

#### 4.3.2 创建新页面

1. 点击「**新增**」按钮
2. 进入页面编辑页面
3. 切换到「页面信息」标签：
   - **页面名称**：填写页面名称，如「关于我们」
   - **页面路由**：填写访问地址，如 `/about.html`
     - 首页路由填 `/`
     - 其他页面建议以 `.html` 结尾，如 `/about.html`
     - 路由不能重复
   - **绑定布局**：从下拉框选择一个已创建的布局（必须先创建布局才能创建页面）
   - **导航样式**：选择 `light` 或 `dark`（覆盖全局导航样式）
   - **SEO 标题/描述/关键词**：单独配置该页面的 SEO 信息
4. 切换到「页面内容」标签，进入可视化设计器
5. 从左侧组件面板拖拽各种内容组件到画布上
6. 点击组件进行配置，可以设置文字、图片、链接等属性
7. 拖拽组件调整上下顺序
8. 点击右下角「**保存**」

#### 4.3.3 编辑页面

1. 在页面列表中找到要修改的页面
2. 点击「**编辑**」
3. 可以修改页面信息（路由、SEO 等），也可以在设计器中调整页面内容
4. 点击「**保存**」

#### 4.3.4 删除页面

1. 在页面列表中找到要删除的页面
2. 点击「**删除**」
3. 确认删除

> ⚠️ **注意**：内置页面（文章列表页、文章详情模板、咨询页面）的「删除」按钮是禁用的，不能删除。

### 4.4 内置页面说明

系统预置了三个**内置页面**，这些是功能型页面，不能删除，路由固定：

| 内置页面 | 路由 | 说明 |
|----------|------|------|
| 文章列表页 | `/information.html` | 展示所有文章的列表，包含分类筛选 |
| 文章详情模板 | `/information/detail-{id}.html` | 文章详情页模板，`{id}` 会自动替换为文章 ID |
| 咨询页面 | `/consultation.html` | 访客填写咨询表单的页面 |

**内置页面的特点**：
- 路由固定，不能修改
- 不能删除
- 内容可以通过可视化设计器自定义
- 文章列表页和文章详情页会**自动关联文章管理中的数据**

### 4.5 可视化设计器使用指南

**进入方式**：编辑页面/布局时，切换到「页面内容」或「布局内容」标签。

#### 4.5.2 添加组件

1. 在左侧组件面板中找到需要的组件
2. 组件按类别分组：布局、Banner与头部、能力与展示、产品与资源、案例与行业、内容与关于、表单与交互
3. 点击组件名称，或拖拽组件到画布上
4. 组件会添加到画布底部

#### 4.5.3 配置组件属性

1. 在画布上点击要配置的组件
2. 右侧「组件属性」面板会显示该组件可配置的属性
3. 根据属性类型填写：
   - **文本**：直接输入文字
   - **图片**：输入图片 URL，或从素材库选择
   - **链接**：输入跳转地址，如 `/about.html`
   - **开关**：点击切换启用/禁用
   - **数组**：如轮播图的图片列表，可以添加、删除、排序
4. 配置会实时反映在画布预览中

#### 4.5.4 调整组件顺序

- **上移**：点击组件工具栏的「↑」按钮
- **下移**：点击组件工具栏的「↓」按钮
- 或者直接拖拽组件调整位置

#### 4.5.5 删除组件

1. 在画布上点击要删除的组件
2. 点击组件工具栏的「删除」按钮
3. 确认删除

#### 4.5.6 常用组件说明

**布局类组件（仅在布局编辑中使用）**：

| 组件 | 用途 |
|------|------|
| NavMenu | 顶部导航栏，配置菜单项和 Logo |
| SiteFooter | 底部页脚，配置版权信息、链接等 |
| FloatingSidebar | 悬浮侧边栏，如右侧客服按钮 |
| 内容插槽 | 页面内容的占位符，布局中必须有且仅有一个 |

**内容类组件（在页面编辑中使用）**：

| 组件 | 用途 | 典型配置 |
|------|------|----------|
| SwiperCarousel | 轮播图/Banner | 图片、标题、副标题、按钮、跳转链接 |
| ProductMatrix | 产品矩阵展示 | 软件产品、硬件产品、服务产品的分类展示 |
| CaseShowcase | 案例展示 | 案例图片、标题、副标题、跳转链接 |
| BusinessIconMarquee | 合作企业 Logo 滚动展示 | Logo 图片列表 |
| NewsSection | 文章/资讯列表 | 标题、查看更多链接、显示数量 |
| EngineCards | 能力卡片展示 | 图标、名称、描述、跳转链接 |
| **RichText（富文本）** | **富文本/HTML内容** | **任意 HTML + CSS 代码，支持AI生成美观内容** |
| ConsultationForm | 咨询表单 | 表单标题、字段标签、背景图 |
| CategoryTabs | 分类标签栏 | 分类名称、跳转链接 |
| ArticleDetail | 文章详情（模板变量） | 标题、时间、内容占位符 |

> 💡 **提示**：组件的具体配置项因组件而异，选中组件后右侧配置面板会显示所有可配置项。大多数配置项都有直观的标签说明。

#### 4.5.7 RichText 富文本组件详解（强烈推荐使用）

RichText（富文本）是页面设计中最强大、最灵活的组件。**强烈推荐在需要展示复杂图文内容时使用它，而不是依赖多个固定组件拼凑。**

##### 为什么 RichText 是最强组件？

| 能力 | 说明 |
|------|------|
| **任意 HTML** | 可以插入完整的 HTML 代码，包括 `div`、`section`、`table`、`ul/ol` 等任何标签 |
| **完整 CSS** | 支持内联样式（`style` 属性）和 `<style>` 标签，可以实现任意视觉效果 |
| **响应式布局** | 可以编写 Flexbox、Grid 布局，实现多列图文排版 |
| **动画效果** | 支持 CSS 动画、`@keyframes`、过渡效果（`transition`） |
| **图标字体** | 可以引入 Font Awesome 等图标库的 CDN 链接 |
| **iframe 嵌入** | 可以嵌入地图、视频、第三方页面等 |

**换句话说**：只要你能写出 HTML + CSS 代码，RichText 就能把它渲染到页面上。它相当于一个"万能内容容器"。

##### 使用 AI 生成美观的富文本代码

**强烈推荐使用 AI 工具（如 ChatGPT、Claude、Kimi、DeepSeek 等）来生成 RichText 的 HTML 代码。**

你不需要会写代码，只需要告诉 AI 你想要什么效果，AI 会自动生成完整的 HTML + CSS 代码。然后你只需要：

1. 在可视化设计器中添加 **RichText** 组件
2. 将 AI 生成的 HTML 代码粘贴到 RichText 的内容配置中
3. 保存页面，构建发布后即可看到效果

##### 使用 RichText 的注意事项

1. **图片路径**：AI 生成的代码中如果包含图片，请将占位符 URL 替换为素材管理中的真实图片 URL
2. **字体图标**：如果使用 Font Awesome 等图标库，需要在 HTML 中引入对应的 CDN 链接
3. **样式隔离**：RichText 中的样式只会影响当前组件，不会影响页面其他部分
4. **代码检查**：粘贴代码后，建议先在设计器中预览效果，确认无误后再保存
5. **性能**：不要在 RichText 中插入过大的图片或视频，建议使用素材管理中的文件并引用 URL
6. **兼容性**：避免使用过于前卫的 CSS 特性，确保在主流浏览器中正常显示

##### RichText 适用场景

| 场景 | 为什么用 RichText |
|------|-------------------|
| 公司介绍 | 固定组件难以实现复杂的图文混排 |
| 团队展示 | 需要自定义头像排列和 hover 效果 |
| 数据展示 | 计数动画、渐变色数字等特效 |
| 时间轴 | 左右交替布局，固定组件无法实现 |
| 复杂表格 | 产品参数对比、价格表等 |
| FAQ 问答 | 手风琴折叠效果、自定义样式 |
| 客户评价 | 卡片式布局，带引号装饰、星级评分 |
| 合作伙伴 | Logo 网格排列，hover 效果 |

> 💡 **核心建议**：当系统提供的固定组件无法满足你的排版需求时，**不要勉强拼凑**，直接使用 RichText + AI 生成代码，效果往往更好、更灵活。

#### 4.5.8 布局编辑 vs 页面编辑的组件差异

| | 布局编辑 | 页面编辑 |
|--|----------|----------|
| 可用组件 | NavMenu、SiteFooter、FloatingSidebar、内容插槽 | 除布局组件外的所有内容组件 |
| 用途 | 搭建全局框架 | 搭建页面具体内容 |
| 影响范围 | 所有绑定该布局的页面 | 仅当前页面 |

## 5. 文章管理

**入口**：后台左侧菜单 →「文章管理」

文章管理用于维护网站的资讯/新闻内容，支持分类体系和富文本编辑。

### 5.1 文章分类

**入口**：后台左侧菜单 →「文章管理」→「文章分类」

#### 5.1.1 功能说明

- 文章分类是一级分类，暂不支持多级嵌套
- 分类用于文章列表页的筛选和分组展示
- 系统内置了四个默认分类：公司动态、行业新闻、产品动态、政策报告

#### 5.1.2 创建分类

1. 点击「**新增**」按钮
2. 在弹窗中填写：
   - **分类名称**：如「技术博客」
   - **排序**：数字越小排序越靠前
   - **显示状态**：启用/禁用
3. 点击「确定」

#### 5.1.3 编辑分类

1. 在分类列表中找到要修改的分类
2. 点击「**编辑**」
3. 修改信息后点击「确定」

#### 5.1.4 删除分类

1. 在分类列表中找到要删除的分类
2. 点击「**删除**」
3. 确认删除

> ⚠️ **注意**：删除分类前，请先确保该分类下没有文章，否则文章将失去分类归属。

#### 5.1.5 切换显示状态

在分类列表中，可以直接点击「显示状态」列的开关，快速启用或禁用某个分类。禁用的分类不会在前端展示。

### 5.2 文章列表

**入口**：后台左侧菜单 →「文章管理」→「文章列表」

#### 5.2.1 功能说明

- 展示所有文章的列表
- 支持按文章标题搜索
- 支持按分类筛选
- 支持分页浏览

#### 5.2.2 列表字段说明

| 字段 | 说明 |
|------|------|
| 标题 | 文章标题 |
| 分类 | 文章所属的分类 |
| 作者 | 文章作者 |
| 显示状态 | 启用/禁用，禁用后文章不在前端展示 |
| 创建时间 | 文章首次创建时间 |
| 更新时间 | 文章最后修改时间 |

#### 5.2.3 新增文章

1. 点击「**新增**」按钮
2. 进入文章编辑页面

#### 5.2.4 编辑文章

1. 在文章列表中找到要修改的文章
2. 点击「**编辑**」

#### 5.2.5 删除文章

1. 在文章列表中找到要删除的文章
2. 点击「**删除**」
3. 确认删除

#### 5.2.6 切换显示状态

在文章列表中，可以直接点击「显示状态」列的开关，快速启用或禁用某篇文章。

### 5.3 文章内容编辑

**入口**：新增/编辑文章时进入

#### 5.3.1 文章信息

| 字段 | 必填 | 说明 |
|------|------|------|
| 标题 | ✅ | 文章标题 |
| 摘要 | ❌ | 文章摘要，用于列表页展示 |
| 分类 | ✅ | 选择文章所属的分类 |
| 封面图 | ❌ | 文章封面图，用于列表页展示。点击「选择素材」从素材库选取 |
| 作者 | ❌ | 文章作者名称 |
| 正文 | ❌ | 文章正文内容 |

#### 5.3.2 编辑器模式切换

文章正文支持两种编辑模式：

**富文本编辑模式（默认）**：
- 类似 Word 的可视化编辑器
- 支持加粗、斜体、标题、列表、链接等常见格式
- 支持插入图片（从素材库选择）
- 适合不熟悉 HTML 的用户

**源码编辑模式**：
- 直接编辑 HTML 代码
- 适合需要精确控制 HTML 结构的高级用户
- 可以插入自定义 HTML、内联样式等

切换方式：正文区域上方有「富文本编辑」和「源码编辑」两个单选按钮。

#### 5.3.3 插入图片

1. 将光标放在要插入图片的位置
2. 点击编辑器工具栏的「**插入图片**」按钮
3. 在弹出的素材选择窗口中选择图片
4. 点击「确定」，图片会插入到光标位置

> 💡 **提示**：图片必须先从「素材管理」上传到素材库，才能在文章中插入。

#### 5.3.4 保存文章

编辑完成后，点击右下角「**保存**」按钮：
- 新增文章：保存后会创建新文章
- 编辑文章：保存后会更新已有文章

> ⚠️ **注意**：保存文章后，**线上网站不会立即更新**。需要到「构建部署」页面重新构建并发布。

| 新加坡 | `as0` |

如果不确定，可以在七牛云控制台 → 空间管理 → 点击你的空间 → 查看「存储区域」。

### 8.3 保存配置

填写完所有信息后，点击「**保存**」按钮。配置会保存在系统中，供后续构建部署时使用。

> 💡 **提示**：部署配置只需设置一次，除非更换了七牛云账号或 Bucket，否则不需要频繁修改。

## 9. 构建部署

**入口**：后台左侧菜单 →「构建部署」

**功能**：将后台配置的所有内容（页面、布局、文章、素材引用等）构建成静态 HTML 站点，并部署到七牛云 CDN。

### 9.1 页面说明

```
┌─────────────────────────────────────────────┐
│  [新建制品]                                  │  ← 右上角按钮
├─────────────────────────────────────────────┤
│  制品名 [________] 构建状态 [▼] 发布状态 [▼] 自动刷新 [▼] │  ← 筛选表单
├─────────────────────────────────────────────┤
│  制品名      │ 构建状态 │ 发布状态 │ 最近发布成功时间 │ 操作  │
│  ────────────┼─────────┼─────────┼─────────────────┼──────│
│  site-v1.zip │  成功   │  成功   │ 2024-04-29 10:00│ 再次发布│
│  site-v2.zip │  成功   │  失败   │       --        │ 发布   │
└─────────────────────────────────────────────────────────────┘
```

### 9.2 状态说明

| 状态 | 颜色 | 含义 | 操作建议 |
|------|------|------|----------|
| 待处理 | 灰色 | 任务已创建，正在排队等待执行 | 等待系统自动执行 |
| 执行中 | 蓝色 | 正在构建或部署中 | 耐心等待，不要重复操作 |
| 成功 | 绿色 | 构建/部署完成 | 可以访问网站验证 |
| 失败 | 红色 | 构建或部署过程中出错 | 联系技术人员查看后端日志 |

### 9.3 新建制品（触发构建）

1. 点击页面右上角「**新建制品**」按钮
2. 系统会创建一个构建任务，状态变为「执行中」
3. 构建过程包括：
   - 读取所有页面、布局、文章、站点配置
   - 将可视化设计器中的组件渲染为 HTML
   - 生成静态文件（HTML、CSS、JS、图片等）
   - 打包为压缩文件
4. 等待构建完成（通常需要几十秒到几分钟）
5. 构建成功后，「构建状态」变为绿色「成功」

> 💡 **提示**：可以通过筛选表单的「自动刷新」选项设置页面自动轮询时间（30秒 / 1分钟 / 5分钟），无需手动刷新页面查看进度。

### 9.4 发布制品（部署上线）

构建成功后，需要点击「发布」才能将内容部署到线上：

1. 找到构建成功的记录，点击「**发布**」按钮
2. 系统会自动执行以下操作：
   - 将构建产物上传到七牛云对象存储 Bucket
   - 覆盖旧文件（同名文件会被新文件覆盖）
   - 触发 CDN 刷新，清除缓存
3. 等待「发布状态」变为绿色「成功」
4. 此时访问你的网站地址，应该能看到最新内容

### 9.5 重新发布

如果某次发布失败了，或者你想将历史某个构建版本重新部署上线：

1. 找到对应的构建记录
2. 点击「**再次发布**」按钮
3. 系统会重新执行部署流程

> 💡 **提示**：「再次发布」不会重新构建，只是将已有的构建产物重新上传到七牛云并刷新 CDN。如果需要更新内容，应该先「新建制品」构建新版本。

### 9.6 修改后如何生效

无论你修改了站点设置、页面内容、文章、布局中的任何一项，**都需要重新构建并发布才能在线上生效**：

```
修改内容 → 点击「新建制品」→ 等待构建成功 → 点击「发布」→ 线上生效
```

## 10. 七牛云踩坑记录

> 以下问题均为实际运营中遇到的真实踩坑经验，请仔细阅读以避免重复遇到问题。

### 坑 1：覆盖上传失败（第二次部署时文件无法覆盖）

**现象**：第一次发布成功，第二次点击「再次发布」时，文件上传失败，报错 `614 file exists`。

**原因**：七牛云普通上传默认不允许覆盖同名文件，需要特殊配置才能覆盖。

**解决**：已在系统中修复，现在每次部署都会正确覆盖旧文件。如果仍然遇到此问题，请联系技术人员升级后端版本。

---

### 坑 2：根目录传入刷新目录参数导致整次 CDN 刷新失败

**现象**：部署日志显示文件上传成功，但 CDN 刷新失败，错误信息提示根目录 URL 被标记为无效。

**原因**：七牛云平台判定 `https://你的域名/` 这种根目录格式为**无效目录参数**，只要有任何一个无效参数，整次刷新请求就会被拒绝。

**解决**：已在系统中修复，现在部署时**只刷新 URL 列表，不再传入目录参数**。

**工程师原话**：
> "根目录不能传入 dirs 参数，平台会判定为无效目录，导致整次请求被拒绝。如果需要刷新子目录，dirs 中必须传入具体的子目录路径，且以 `/` 结尾，如 `https://domain/assets/`。"

---

### 坑 3：CDN 刷新额度耗尽导致部署失败

**现象**：一切配置都正确，但发布时 CDN 刷新步骤报错，提示额度不足。

**原因**：七牛云 CDN 刷新有**每日额度限制**：
- **URL 刷新**：每日有限额，用完需等次日 0 点重置
- **目录刷新**：每日有限额，且额度通常更少

**解决**：
1. 检查七牛云控制台 →「CDN」→「刷新预取」→ 查看当日剩余额度
2. 如果额度已用完，**只能等待次日自动重置**
3. 频繁调试期间，可以让技术人员临时关闭 CDN 刷新逻辑，只保留文件上传
4. 正式上线后，建议联系七牛客服申请提升刷新额度

---

### 坑 4：CDN 刷新接口返回成功但实际没刷新

**现象**：部署日志显示「CDN 刷新成功」，但访问网站时看到的还是旧页面，缓存未清除。

**原因**：七牛云 CDN 刷新接口的设计是：HTTP 状态码 200 只代表请求到达服务器，不代表刷新真的成功了。真正的成功标志在响应内容里。

**解决**：已在系统中修复，现在会正确检查刷新结果。如果仍然遇到缓存未更新的情况，可以：
1. 等待 5-10 分钟（CDN 生效有延迟）
2. 尝试强制刷新浏览器缓存（Ctrl+F5 或 Cmd+Shift+R）
3. 联系技术人员手动调用刷新接口

---

### 坑 5：部署刷新了错误的域名

**现象**：部署成功了，但刷新的是旧的 CDN 域名，新域名没有更新。

**原因**：系统获取 CDN 刷新域名的优先级如下（从高到低）：
1. 构建产物中的站点配置 → 网站地址
2. 原始源码中的站点配置 → 网站地址
3. 部署配置页面中的 Domain 字段

如果构建产物中的配置不正确，就可能刷新到错误的域名。

**解决**：
1. 确保「站点设置」页面中的「网站地址」填写正确
2. 确保「部署配置」页面中的 Domain 与网站地址一致（作为回退）
3. 修改站点设置后，**必须重新构建**（新建制品），新的配置才会被打包进产物

---

### 坑 6：Zone（存储区域）配置问题

**现象**：文件上传速度很慢，或者上传到错误的区域。

**原因**：七牛云不同存储区域（华东、华北、华南等）需要配置对应的 Zone 代码。如果配置错误或留空，可能使用默认区域导致性能问题。

**解决**：在「部署配置」页面的 Zone 字段填写正确的区域代码：

| 区域 | Zone 代码 |
|------|-----------|
| 华东-浙江 | `z0` |
| 华北-河北 | `z1` |
| 华南-广东 | `z2` |
| 北美-洛杉矶 | `na0` |
| 新加坡 | `as0` |

## 12. 最佳实践

### 12.1 内容更新流程

```
1. 在「页面管理」中修改页面内容，或「文章管理」中更新文章
2. 点击「保存」确认修改已保存到后台
3. 进入「构建部署」页面
4. 点击「新建制品」触发构建
5. 等待构建状态变为「成功」
6. 点击「发布」触发部署
7. 等待发布状态变为「成功」
8. 访问网站验证更新是否生效
```

### 12.2 日常维护建议

1. **站点设置和部署配置的域名保持一致**：避免回退逻辑导致刷新到错误域名
2. **修改任何内容后务必重新构建**：配置信息、页面内容、文章等只在构建时被打包进产物
3. **定期检查七牛云刷新额度**：避免额度用尽导致发布失败
4. **CNAME 解析生效前不要发布**：确保域名状态「正常」后再操作
5. **不要频繁重复发布**：每次发布都会消耗 CDN 刷新额度
6. **保留 SecretKey 的安全**：不要截图发到聊天群，不要保存在公共文档中
7. **先创建布局，再创建页面**：页面必须绑定布局，没有布局就无法创建页面
8. **素材先上传再使用**：页面组件中使用的图片、文章封面图等，需要先从素材管理上传
9. **批量修改建议集中进行**：避免频繁构建消耗刷新额度，可以先把所有修改做完，再一次性构建发布

### 12.3 新建站点的标准流程

如果你是第一次使用本系统搭建新网站，建议按以下顺序操作：

```
Day 1: 基础配置
  ├─ 完成七牛云控制台配置（Bucket、域名、密钥）
  ├─ 后台「站点设置」填写网站名称、域名、上传 Logo
  ├─ 后台「部署配置」填写七牛云参数
  └─ 后台「素材管理」上传网站所需的图片素材

Day 2: 搭建页面
  ├─ 「页面管理」→「布局列表」创建布局（导航栏 + 内容插槽 + 页脚）
  ├─ 「页面管理」→「页面列表」创建首页，绑定布局，拖拽组件搭建首页内容
  ├─ 创建其他页面（关于我们、产品中心、案例等）
  └─ 配置内置页面（文章列表页、咨询页面）的内容

Day 3: 内容填充
  ├─ 「文章管理」→「文章分类」创建分类
  ├─ 「文章管理」→「文章列表」撰写文章
  └─ 检查所有页面的 SEO 配置

Day 4: 发布上线
  ├─ 「构建部署」→「新建制品」触发构建
  ├─ 等待构建成功
  ├─ 点击「发布」部署上线
  └─ 访问域名验证网站是否正常
```
