# 素材管理 PRD

> 搭配 file 服务（`prod/cube/apps/file`）使用

---

## 1. 需求概述

素材管理模块提供可视化界面管理静态素材资产，包括图片、视频、字体等。素材存储至已对接的 miniO 对象存储服务，页面采用 Windows 文件管理器风格（地址栏导航 + 内容区），并提供素材选择弹窗供其他业务模块调用。

## 2. 功能列表

### 2.1 素材管理

| 功能 | 说明 |
|------|------|
| 目录管理 | 支持多级目录创建、编辑、删除 |
| 素材上传 | 支持单文件/批量上传，类型包括图片、视频、字体等 |
| 素材列表 | 支持目录切换、类型筛选、搜索 |
| 素材编辑 | 重命名素材、移动目录 |
| 素材删除 | 支持单选/多选删除 |
| 批量操作 | 批量移动、批量删除 |

### 2.2 素材选择弹窗

提供业务弹窗，允许其他页面以弹窗方式唤起素材选择器，选取素材后返回素材信息。

## 4. 页面说明

### 4.1 素材管理主页面

采用 Windows 文件管理器布局：**顶部地址栏 + 底部内容区**

- **顶部地址栏**
  - 展示形式：`全部素材 / 图片 / 产品图`
  - 点击路径片段可快速跳转到对应目录
  - 点击面包屑最后一段可进入编辑状态（重命名目录）

- **工具栏**
  - 新建文件夹按钮
  - 上传按钮
  - 搜索框
  - 类型筛选（全部/图片/视频/字体/其他）

- **内容区**
  - 当前目录下的子文件夹（显示文件夹图标）
  - 当前目录下的素材（显示缩略图或文件图标）
  - 右键菜单：打开、重命名、移动、删除
  - 双击文件夹进入下一级目录
  - 双击素材打开预览

- **素材卡片**
  - 缩略图/图标
  - 素材名称（超长省略）
  - 文件大小

- **素材上传**
  - 拖拽上传：拖拽文件到内容区触发上传
  - 点击上传按钮：弹出文件选择器
  - 显示上传进度条
  - 支持多文件同时上传
  - 上传完成后自动刷新当前目录

- **目录操作**
  - 新建文件夹：弹窗输入目录名称
  - 重命名：直接编辑或弹窗修改
  - 删除：需确认（有内容时提示迁移）

### 4.2 素材选择弹窗

- 弹窗模式调用，不单独做路由
- 顶部地址栏导航（与主页面一致）
- 支持目录选择、搜索、类型筛选
- 支持单选/多选模式
- 确定后回调选中素材信息

## 5. 数据模型

### 5.1 素材目录 (MaterialFolder)

```typescript
interface MaterialFolder {
  id: string;
  pathId: string | null;  // 父目录ID，null 表示根目录
  name: string;             // 目录名称
  sort: number;             // 排序
  createdTime: string;
  updatedTime: string;
}
```

### 5.2 素材 (Material)

```typescript
interface Material {
  id: string;
  pathId: string | null;  // 所在目录ID
  name: string;             // 素材名称（不含后缀）
  ext: string;               // 文件扩展名（如 png, jpg, mp4）
  mimeType: string;         // MIME类型
  size: number;             // 文件大小（字节）
  createdTime: string;
  updatedTime: string;
}
```

> ⚠️ 素材 URL 不存储，通过素材 ID 实时查询获取

---

## 6. 注意事项

> ⚠️ 删除目录时，需检查目录下是否有素材/子目录，如有则提示用户先迁移或删除
> ⚠️ 删除素材时，增加二次确认
> ⚠️ 上传同名文件时，提示是否覆盖
> ⚠️ 素材选择弹窗需考虑大量素材时的性能，可采用虚拟滚动
> ⚠️ 地址栏路径过长时，前面路径片段可收缩展示
