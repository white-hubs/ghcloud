## 页面说明

### 1. 站点设置

- **页面基本配置**
  - 网站名称（必填）
  - 网站地址（必填）
  - 分享图（必填，OG 图片）
  - Favicon（必填）
  - 主色
  - 导航样式（light / dark）
- **全局默认 TDK**
  - defaultTitle
  - defaultDescription
  - defaultKeywords
- **统计代码配置**（List，可配置多个）

### 2. 页面管理

- **页面列表**
  - 表格展示：页面名称、页面路由、页面标题、绑定布局、创建时间、更新时间
  - 操作：新增、编辑、删除
- **页面布局列表**
  - 表格展示：布局名称、创建时间、更新时间
  - 操作：新增、编辑、删除
- **页面布局设计**
  - 设计组件（Design Panel）：页面信息 + 页面设计
  - 页面信息：页面名称、页面路由、页面级 TDK、navStyle
  - 页面设计：拖拽配置 + 组件属性配置
  - JSON 配置：网页版 vscode
- **页面内容设计**
  - 表单：页面名称、页面路由、页面标题、关键词、描述、绑定布局、Components 配置
  - 复用设计组件

### 3. 素材管理

- **主页面**：Windows 文件管理器布局
  - 地址栏导航：`全部素材 / 图片 / 产品图`
  - 工具栏：新建文件夹、上传、搜索、类型筛选
  - 内容区：文件夹 + 素材卡片
  - 拖拽上传
- **素材选择弹窗**
  - 供其他业务模块调用

### 4. 文章管理

- **文章列表**
  - 表格展示：标题、分类、创建时间、更新时间
  - 操作：新增、编辑、删除、排序
- **文章内容编辑**
  - 表单：标题、日期、摘要、分类、封面图、作者、正文
- **文章分类**
  - 表格展示：分类名称、创建时间、更新时间
  - 操作：新增、编辑、删除
  - 仅支持一级分类
- **页面设计（已统一到页面管理）**
  - 文章列表页和文章详情页作为内置页面，统一在「页面管理」中维护
  - 文章列表页：内置路由 `/information`
  - 文章详情页：内置路由 `/information/detail-{id}.html`

### 5. 咨询管理

- **咨询列表**
  - 表格展示：姓名、联系方式、企业名称、应用场景、创建时间
  - 操作：删���
- **页面设计（已统一到页面管理）**
  - 咨询页面作为内置页面，在「页面管理」中维护

### 6. 网站发布

- **发布配置**
  - 部署目标：七牛云（可选：SFTP/FTP，提示暂不支持）
- **发布执行**
  - 发布按钮
  - 制品列表：制品名、构建状态、发布状态、最近发布成功时间
  - 再次发布

## 设计组件（Design Panel）

**公共设计组件**，被以下页面共用：

- 页面管理：页面布局设计、页面内容设计（含文章列表页、文章详情页、咨询页等内置页面）

**功能**：
- Tab 1：页面信息（名称、路由、TDK、navStyle）
- Tab 2：页面设计（拖拽配置、组件属性配置）
- 路由编辑禁用（内置路由不可修改）

---

> ⚠️ **关于 SSG 内置功能**：
> - 文章列表页：固定路由 `/information`，不可自定义
> - 文章详情页：路由 `/information/detail-{id}.html`，由 generator-cli 自动生成
> - 咨询页：固定路由 `/consultation`，不可自定义

> 📖 **参考**：`generator-cli/test-site` 下有配置 demo
